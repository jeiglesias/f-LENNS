# Model weights

This directory is where f-LENNS keeps the pretrained model, `f-LENNS.pth`.

You normally do not need to do anything: the first time you run f-LENNS, the
weights are downloaded here automatically and reused on every subsequent run.
The file is not tracked by git.

If the automatic download does not work (no outbound internet access, proxy,
firewall), see the "Manual download" section of the top-level
[README](../README.md).
